# Curso React Ejercicios

Repositorio con los ejercicios y proyectos del curso de React en Udemy. Cada carpeta corresponde a un módulo o sección del curso.

## 📁 Estructura del proyecto

| Carpeta | Descripción |
|---|---|
| `react-ts-bases` | Bases de JavaScript/TypeScript moderno: const/let, template strings, destructuring, promesas, fetch, async/await |
| `react_1` | Primeros pasos con React: componentes funcionales, JSX, props y estilos. Incluye un buscador de Pokémon |
| `react_2` | Componentes, helpers matemáticos y carrito de compras con contador de items |
| `react_3_gifs` | Aplicación de búsqueda de GIFs con la API de Giphy, custom hooks, tests y snapshots |
| `react_4_hooks` | Hooks de React: useState, useEffect, useRef, useReducer. Semáforo interactivo, página de Pokémon y gestor de tareas |
| `react-first-steps` | Proyecto con TypeScript, tests unitarios con Vitest, snapshots y cobertura de código |

## 🛠️ Tecnologías utilizadas

- React 18
- TypeScript
- Vite
- Vitest (testing)
- CSS Modules
- API de Giphy

## 🚀 Cómo ejecutar cada proyecto

1. Entra en la carpeta del proyecto que quieras ejecutar:
   ```bash
   cd react_1
````

2. Instala las dependencias:

   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```
